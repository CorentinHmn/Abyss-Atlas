# SCR-010 — Projects list

Status: Draft
Last updated: 2026-11-06

| Address | Who | Phase | Requirements |
|---|---|---|---|
| `/projects` | members | P2 | ADM-040, ADM-042, ADM-043, NAV-013 |

## 1. Purpose
Find and open the organization's projects; create one.

## 2. Content
- One card or row per project: name, description, number of models, validation status, last change (who, when).
- Archived projects in a separate tab (ADM-042).

## 3. Actions
- **Open** a project (SCR-011).
- **New project** (Editors, Admins): name, description (ADM-040).
- Search by name.

## 4. States and errors
- No project yet: a short explanation and the **New project** button (or, for Viewers, "No project has been shared yet").
- Common rules: `docs/06-ux/screens/README.md` §2.
