# SCR-081 — Organization: domains

Status: Draft
Last updated: 2026-11-06

| Address | Who | Phase | Requirements |
|---|---|---|---|
| `/org/domains` | Admins (members read) | P2 | ADM-050…ADM-053 |

## 1. Purpose
Define the organization's business processes shared by all projects.

## 2. Content
- Domains: code, name, description, status (active, retired), number of objects using them.

## 3. Actions
- **New domain**, rename, describe, retire, reactivate (ADM-050…ADM-052).
- Owners and stewards come in P3 (ADM-053).

## 4. States and errors
- No domain yet (new organization): explanation with examples; projects cannot create models until a domain exists.
- Common rules: `docs/06-ux/screens/README.md` §2.
